## Tugas Mandiri P2

Dokumen ini menjadi pendahuluan pelaksanaan Tugas Mandiri P2 yang terdiri dari TM-1 sampai TM-5.

Tugas Mandiri P2 dikerjakan secara individu untuk memahami routing API, HTTP method dan status code, paradigma komunikasi API, penggunaan HTTP client dan DevTools, serta perbandingan raw SQL dengan ORM.
